# Running Python Code

Write Python in a cell running the **Python** or **Python AI** agent, then run
it with **Run cell** (⌘+Enter).

## Getting data in

- **Named values** from earlier cells — a dataframe another cell produced
- **Input group parameters**, referenced with a leading colon: a parameter named
  `amount` is `:amount` in your code. See
  [Input Groups](031_Input_Groups.md)

## Getting results out

- **The last expression** in the cell is displayed automatically
- **`save_artifact(data, "name")`** saves and names an output explicitly, and
  can be called several times in one run

Named outputs become named values, usable by later cells and listed in the
**Variables** panel. See [Python Outputs](024_Python_Outputs.md) for the types
`save_artifact` accepts.

Because the sandbox is stateless, naming an output is the only way to carry
anything to the next cell — see [The Python Sandbox](020_Python_Sandbox.md).
