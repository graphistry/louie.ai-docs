# Adding Cells

New cells are added from the toolbar attached to each cell, or from the composer
at the bottom of the notebook.

## The three cell types

| Button | What it adds |
|---|---|
| **Add cell** | A prompt cell, run by an agent of your choosing |
| **Add markdown cell** | Formatted notes. No agent, nothing to run |
| **Add input group cell** | Parameters that later cells can read |

## Ordering and removing

**Move cell up** (Alt+Shift+Up) and **Move cell down** (Alt+Shift+Down) reorder
a cell; **Delete cell** removes it.

A `+` control sits between cells, so a new cell can be inserted at any point
rather than only at the end.
