# Main Area and Notebooks

The main area is where analysis happens. Work is organised into **notebooks**,
each one a container for a line of enquiry and everything it produced.

## The pieces

- **Notebook** — a series of cells: requests, their outputs, and the reasoning
  behind them
- **Main area** — the working surface, with the notebook open in it
- **Sidebar** — folders, notebooks, skills and your account context

## Working with notebooks

Notebooks keep related work together, so returning to an investigation means
reopening one rather than reassembling it. Because every cell's output stays
attached to the request that produced it, a notebook is also a record of how a
conclusion was reached, not only the conclusion.

Notebooks in a shared folder are visible to the organization; those in
**Personal** are yours alone. A notebook can be moved between them with
**Copy to org…** from its ⋯ Actions menu.

Each notebook has two views: **Notebook** for the working cells, and
**Dashboard** for presenting selected outputs as panels. See
[Notebook vs Dashboard Tabs](027_Notebook_vs_Dashboard_Tabs.md).
