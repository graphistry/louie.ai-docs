# Talking to Your Data

Louie is a GenAI-first analyst platform for talking to data.

Ask a question in plain language and Louie works out which source to query, how
to query it, and how to present the answer — then shows you each step it took,
so the result can be checked rather than taken on trust.

## What that gives you

- **Structure** — generative AI and graph AI over databases, documents and more
- **Conversation** — a question in plain language, with an API for the same thing headlessly
- **Visualization** — GPU-accelerated graph, map and chart rendering

Answers are interactive, not static: tables sort and filter, charts reconfigure,
graphs expand. What a cell produces is available to the next one, so an
investigation builds rather than restarts.
