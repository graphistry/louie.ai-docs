# API

Louie's API exposes the same agents and notebooks that the UI uses, for
automation, embedding and headless work.

Full reference, including live request testing, is served by your own
deployment at:

```
https://<your-louie-host>/api/docs
```

Reading it there rather than from static documentation matters: the schema
reflects the version you are running.

## Authentication

Requests carry a JWT:

```
Authorization: Bearer <token>
```

## Shape

- **Chat** — start a new session or continue an existing one, streaming or
  blocking
- **Data** — fetch tables referenced by a response, as JSON or Arrow
- **Media** — fetch charts, graphs and other rich output a response refers to

See [Louie API for Conversational Analytics](067_Louie_API_for_conversational_analytics__Embedding__headless___.md)
for the conversational endpoints, and
[Launch Deep Links](071_Launch_Deep_Links.md) for opening Louie
pre-loaded from another tool.
