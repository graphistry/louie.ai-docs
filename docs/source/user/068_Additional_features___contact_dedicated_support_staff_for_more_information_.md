# Additional Features

## Agents

Every cell runs through an agent. Passthrough agents send your input straight to
the tool; AI agents interpret a plain-language request first.

**Passthrough** — Chart · Graph · Kusto · Mermaid · Python · Spanner · Splunk · UMAP

**AI** — Chart AI · Graph+UMAP AI · Kusto AI · Map · MCP AI · Mermaid AI ·
Notebook AI · Python AI · Spanner AI · Splunk AI · Table AI · Text AI

The list reflects what your organization has configured — a connector type with
no connector set up does not appear.

## Connectors

Twelve types, including MCP for any MCP-compatible server. See
[Data Connectors](connectors_overview.md).

## Analysis and visualization

- Tables and dataframes, sortable and filterable in place
- Perspective charts, with cross-filtering
- Graphistry GPU graph visualization
- GPU map rendering
- UMAP clustering
- Mermaid diagrams
- Python in a sandbox, with the usual data-science stack

## Platform

- API with authentication, streaming and batch
- Skills, including upload and authoring
- Timelines
- Dashboards built from notebook outputs
- Sharing within and across organizations
- Administration: setup, hardening, backups

For anything not covered here, contact support@louie.ai.
